The unified methodology

One test. Applied to every nucleus.

No more "promoted" versus "published". Both have to earn the verdict through the same word-evidence pass.

  1. Pull every actual word.
    Quranic + classical Arabic forms derived from the nucleus's trilateral family. The evidence is the words, not the abstract reading.
  2. Categorize each word's face.
    Inward (held, contained, gathered) or outward (emerging, spreading, going-forth) — the two fundamental semantic axes.
  3. Count the faces.
    If the family clusters on one face, the nucleus has one reading. If on two, it's dual-face.
  4. Verdict.
    Proved 1-face, proved 2-face, or under-tested. Zero "contradicted" cases.

Edge cases · the originally not-earned

The 4 nuclei that broke the auto-grading.

Each was diagnosed manually. All four now have either a promoted reading (via a letter dual-face refinement) or a methodological explanation.

ثن
Diagnosis D
Add ن to Variants — the رَنين face (cavity-held) vs انبِعاث face (outward)
Proposed reading
«تَناثُرٌ يَنطَوي في باطنٍ رَنين»
fine spread folded into a held interior

The family is internally coherent around two-ness folding inward / fine accumulation held (ثنى = folding into bends; ثنن = interiorization of fine particles; وثن = the held-erected thing). The original grading read ن as outward emission only, but ن's published «رَنين + انبِعاث» phrasing already encodes two physical phases: the رَنين (cavity-held resonance, in-place ringing) comes BEFORE any emission. When the first letter is itself fine/granular (ث), the family activates the رَنين face, giving 'fine spread folded into a held interior'. This is not a new variant — it is a recognition that ن's existing phrasing carries two semantic axes, exactly like ب, ع, ف already do in the consensus table.

Recommendation: Add ن to the Variants section of consensus-letter-charges.md with: primary outward face «انبِعاث رَنينيّ» / inward face «رَنين مَحبوس / رَنين جَوفيّ». Then sweep every ن-second-position nucleus with a fine-spread first letter to test how broadly the inward face applies.
ضه
Diagnosis D
Add ه to Variants — the carrying-away exhale face vs gentle-presence face
Proposed reading
«ضَغطٌ يُحمَلُ بالنَّفَسِ فيُسَوَّى»
density carried off by breath until evened out

Single member ضهأ axial = «خلو الشيء مما يتميز به عن غيره» (emptied of what distinguishes it). The original grading punted on data sparsity, but the composition does work if ه is read as physically what it is: the only Arabic letter that's pure exhale, the breath that PASSES THROUGH and CARRIES AWAY. ه's published «همس + تَنَفُّس» phrasing has two phases: همس (gentle, near-silent presence) and تَنَفُّس (the breath that carries off). When dense pressure (ض) is softly breathed off (تَنَفُّس face) and definitively (ء), what remains is emptied of distinction. Same physical exhale, two roles.

Recommendation: Add ه to the Variants section: primary «همس + تَنَفُّس» (gentle exhaled presence) / carrying-away face «نَفَسٌ يَحمِلُ ويَتَلاشى» (breath that carries off, dissipating). Caveat: only one corroborating trilateral so far — propose, but test on other ه-second nuclei before committing to the vault.
ظف
Diagnosis B
Jabal back-projection from a single canonical word
Proposed reading
«(no binary reading)»

Two trilaterals (ظفف, ظفر) and Jabal's binary «الجمع من خارج». But ظُفر (nail, claw) is so canonical and lexicalized that Jabal's binary meaning is almost certainly back-projected from this one famous word. Compositionally: ظ gives edged outward projection (✓ for the nail's hard edge), ف gives parting/opening — neither charge contributes the GATHERING/GRIPPING motion that makes a nail a nail. The grip is a property of the third letter (ر = curl, running-back) and the physical referent. So ظف itself does not have a stable compositional binary reading; it has one lexicalized canonical member that defines the family by retrofit.

Recommendation: Do NOT promote a binary reading for ظف. Flag in the vault as: 'methodologically anomalous — Jabal's binary meaning back-projected from single canonical word ظُفر; family is lexicalized rather than compositional.' Mark family members as one-offs.
ون
Diagnosis B
Acknowledged classical Arabic idiom (single isolated member)
Proposed reading
«(no binary reading)»

Single member ونى = fatigue/cessation. No physical-articulation path from و (sustained link) + ن (resonance) to 'fatigue/cessation' that doesn't depend on a long metaphorical chain. ونى behaves like a lexicalized classical idiom whose meaning is settled by usage rather than by compositional charges. Single-member, semantically isolated.

Recommendation: Acknowledge as isolated classical idiom. No binary reading proposed. No vault edit needed; the variants section does not need to grow to absorb a single outlier.
