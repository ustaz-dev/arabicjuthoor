# خطُّ الاسترداد الشامل للمعاجم

**الحالة:** طبقةُ استرجاعٍ محليّة، لا تُصدر قراءةً ولا حكمًا. تعمل فوق الأدوات المجمّدة من غير تعديلها. **الإصدار:** 2026-07-14.

## ما الذي يضمنه

يثبّت الخط لقطةَ المصدر وحجمها ووقت تعديلها قبل المسح وبعده، ويوقف الشهادة إن تغيّر المصدر في أثناء العمل. ويعطي كل مدخل معرّفًا ثابتًا داخل اللقطة، ثم يسجل واحدًا من مصائر المعالجة بدل إسقاطه صامتًا. ومعرّف Kaikki مركب من هوية المصدر وموضع السطر ومعرّف المعنى، لأن معرّف المعنى وحده قد يتكرر. وهو يضمن اكتمال المرور على **لقطة المصدر المسمّاة** فقط؛ ولا يزعم اكتمال المعجم التاريخي للغة، ولا صحة كل رومنة، ولا صحة أي صلة لغوية.

كل سطر JSON فاسد يوقف شهادة التغطية باسم الملف ورقم السطر، ولا يُتجاوز. وكل رمز غير معروف يوقف التطبيع في الوضع الصارم. وفي الجرد الشامل ينتقل المدخل إلى `blocked-normalization` مع الرمز نفسه كي يصلح الملف ثم يعاد المسح. والمدخل الذي لا يحمل صامتًا، أو كان صورةً صرفية لا لمّة، أو احتاج تحليلًا صرفيًا، يبقى ظاهرًا في حالته ولا يتحول إلى `NO-TRACE`.

## المصادر وملفات التطبيع

| اللغة | لقطة المصدر | ملف التطبيع |
|---|---|---|
| اليونانية القديمة | Kaikki JSONL | `normalization-profiles/ancient_greek.json` |
| القبطية | `Comprehensive_Coptic_Lexicon.xml`، TEI بحقول Crum وDDGLC | `normalization-profiles/coptic.json` |
| اللاتينية | Kaikki JSONL | `normalization-profiles/latin.json` |
| المصرية | بلا مدونة شاملة مربوطة حتى الآن | `normalization-profiles/egyptian.json` |

ملف كل لغة يصرح بخريطة الرسم، والحركات، والرموز المتعددة، والملتبسات، وسياسة الخطوة صفر. ويطبّق تسلسل الطي فعلًا، مثل بقاء /w/ في اللاتينية `qu` بعد طي `q` إلى `k`. لا تنزع الأداة لاصقة صرفية بحدسها؛ ما لم يكن تحليلها مسمى يبقى `morphology-review-required` أو `MORPHOLOGY-GAP` في البطاقة البشرية.

## الحالات المسجلة

| المحور | القيم الأساسية | معناها |
|---|---|---|
| معالجة المدخل | `candidates-generated`، `candidate-search-complete-zero`، `floor-review-required`، `ineligible-form`، `ineligible-nonlexical`، `blocked-normalization`، `blocked-mapping` | ماذا استطاعت آلة الاسترجاع أن تفعل؛ والصفر المكتمل ليس `NO-TRACE` |
| مسار المرشح | `licensed`، `manual-condition`، `scope-gap` | قانون مطبق في نطاقه، أو شرط يحتاج إنسانًا، أو فرصة تتجاوز النطاق الموقّع |
| المراجعة البشرية | `unreviewed`، `reviewed`، `loan-isolated`، `suspended`، `closed` | أين بلغ العمل البشري بعد مرور العدستين |

`scope-gap` ليس رفضًا وليس قانونًا جديدًا. المثال الحارس هو `τρεῖς`: يستبقي الخط صورة `ثر` كي لا تضيع الفرصة، لكنه لا يسميها `licensed` لأن صف `DENT-01` الموقّع عربي آرامي لا يوناني. وكذلك لا تطبق صفوف `BR-*` النصية آليًا؛ يصرح المترجم بأنها يدوية أو مشروطة ويعرضها للمراجع.

## فصل الاسترجاع عن الحكم

قاعدة البيانات المولدة محلية في `cache/recovery_pipeline/inventory-v4.sqlite` وخارج git. فيها لقطة قابلة لإعادة البناء، لا أحكام بشرية. تجمع النتائج المتطابقة في الصورة والحالة فقط إذا تطابقت مجموعة الصفوف أيضًا، فلا يُعرض اتحاد مسارين بديلين كأنه مسار واحد. حالات المراجعة وحدها في `data/recovery-review-states.json` كي لا يبتلع إعادةُ بناء الجرد عملَ المراجعين؛ وتُركّب فوق الجرد عند كل استعلام، فتظهر المراجعة الجديدة فورًا بلا إعادة بناء المعاجم.

لا يجوز نقل مدخل إلى `reviewed` أو `loan-isolated` أو `closed` حتى يسجل:

1. ممر الاسترداد: هل جُرّبت درجات الجذر والأجوف والنواة، ومروحة المعاني، والخلف أو الأخت؟
2. ممر التشكيك: فحص القرض، والمتجانس، وصحة المصدر، والنتيجة المعارضة.

الأداة تتحقق من وجود العدستين، لكنها لا تختار نتيجتهما.

## التشغيل

```powershell
python scripts/recovery_inventory.py profile-check --all --sample 1000
python scripts/compile_shift_network.py --check
python scripts/recovery_inventory.py build --all
python scripts/recovery_inventory.py summary
python scripts/recovery_inventory.py verify
python scripts/recovery_inventory.py query --language coptic --word "ϣⲛϥⲉ"
python scripts/recovery_inventory.py candidates --entry-id "kellia_coptic_lexicon:C5966"
python scripts/generate_candidates.py "τρεῖς"
python scripts/recovery_review.py queue --lens recovery --language coptic
python scripts/recovery_review.py validate
python scripts/check_recovery_pipeline.py
```

يبني `build --all` الجرد من أول مدخل إلى آخر مدخل في كل مصدر موجود. أما `--limit` فعيّنة تشخيصية ويثبت سجل المصدر عندها `coverage_complete=0`، لذلك لا تصلح دليل تغطية.

## حدود الصدق

- الجرد الشامل يعني أن كل مدخل في الملف الخام مر بحالة معلنة، لا أن كل لفظ تاريخي وصل إلى الملف الخام.
- المرشح الصوتي ليس صلة دلالية ولا نسبًا تاريخيًا.
- وسم القرض الآلي قرينة أولية فقط. في القبطية يستفاد من حقول DDGLC اليونانية ونوع المدخل، ثم تبقى قاعدة التوأم واجبة يدويًا.
- المرساة الفمية تسترجع احتمالات؛ لا تُنسب إلى شبكة الإبدالات ولا تُعرض قانونًا تاريخيًا.
- يجوز لمسار الاسترجاع أن يجمع صفوف مقابلة مباشرة في أكثر من خانة، مع تسمية كل صف. أمّا الإبدال العربي الداخلي فيبقى محدودًا بخانة واحدة في المسار الآلي؛ وما زاد على ذلك يحتاج مراجعة يدوية ولا يجوز أن يختفي تحت حكم سلبي.
- لا تدخل أرقام الجرد أو قوائم رؤوسه طبقة النشر أو التحقق إلا بإذن المؤلف وفق الميثاق.
