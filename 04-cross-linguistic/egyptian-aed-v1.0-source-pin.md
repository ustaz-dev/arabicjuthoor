## 2. جرد الحزمة قبل البرمجة

يحتوي الأرشيف `35,174` عضوًا: `35,167` صفحة HTML وسبعة ملفات مساندة.
صفحات HTML تنقسم إلى:

- `33,417` صفحة مدخل معجمي، وعنوان كل منها يبدأ بـ
  `AED - Dictionary entry:`.
- `1,750` صفحة فهرس أو رسم أو صفحة غير معجمية، لا تدخل عدَّ المداخل ولا
  تُسقط بصمت؛ يصرّح المحلّل بعددها.

فحص صفحات المداخل كلها قبل بناء المحلّل أثبت:

| الحقل | الموجود | الغائب أو الفارغ |
|---|---:|---:|
| معرّف اللمّة | 33,417 | 0 |
| الصورة المنقولة | 33,417 | 0 |
| الترجمة الألمانية | 33,398 | 19 |
| الترجمة الإنجليزية | 15,875 | 17,542 |
| معنى بلغة واحدة على الأقل | 33,412 | 5 |
| نوع الكلمة | 33,415 | 2 |
| المعلومة الببليوغرافية | 30,100 | 3,317 |
| قسم `Same root as` | 11,075 | 22,342 |

غياب حقل اختياري لا يحوَّل إلى معنى مخترع ولا يؤدي إلى حذف المدخل. تحفظ
الترجمتان الموجودتان بنصهما مع وسم اللغة، ويظل الحقل الغائب فارغًا ظاهرًا في
تقرير المحلّل.

## 3. عقد الاستخراج الصارم

لا يعدّ المحلّل صفحةً مدخلًا إلا إذا حملت علامة عنوان المدخل المنشورة. ولكل
مدخل يجب أن:

1. يقرأ `lemma id` والصورة المنقولة من الصفحة نفسها، ويوقف التشغيل عند
   غيابهما أو تكرار المعرّف.
2. يحفظ الترجمة الإنجليزية والألمانية بنصهما دون ترجمة أو تحسين؛ إذا وُجدتا
   تحفظان كلتاهما بوسمي `EN:` و`DE:`.
3. يحفظ نوع الكلمة كما نشره AED، ويصرّح بعدد النوع الغائب.
4. يستعمل روابط `Same root as` روابطَ أسرٍ نصيةً ظاهرة، ولا يحوّل
   `Best collocation partners` إلى قرابة معجمية.
5. لا يستنتج قرضًا من الرسم أو المعنى. يبقى مرشح القرض غير معلَّم حتى تفحصه
   مصفاة الاقتراض البشرية بمصدر مسمى.
6. يثبت قبل القراءة الحجم والبصمتين وعدد صفحات المداخل المتوقع `33,417`؛
   أي اختلاف يوقف البناء.
7. يوقف عند رمز نقل غير معروف ولا يسقطه صامتًا. اختلافات النقل المعلنة في
   ملف المصرية تُختبر بأمثلة تحفظ الفروق بين `s/š` و`t/ṯ` و`h/ḥ/ḫ/ẖ`.

## 4. حدود الاستعمال والإسناد

AED هنا أداة استرجاع شاملة داخل حدود اللقطة فقط. لا يصدر المحلّل حكم صلة،
ولا يترجم معنى، ولا يرقّي بطاقة، ولا يولد رقمًا للنشر. كل بطاقة حكم مصرية
تبقى ملزمة بصورة ومعنى ومصدر منشور مسمى من TLA أو *Wörterbuch der
ägyptischen Sprache*، ويجوز استعمال AED شاهد استرجاع وإسناد إضافيًا. لا
يُزحف TLA ولا تُنسخ منه مجموعة كبيرة بموجب هذا القرار.
